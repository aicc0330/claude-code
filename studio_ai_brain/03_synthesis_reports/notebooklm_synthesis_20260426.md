## 📋 實際應用步驟

### 使用 HappyHorse 1.1 的基本工作流

**步驟 1**：準備輸入
```
輸入文本提示詞：
"beautiful landscape with mountains, sunset lighting, 
photorealistic, 8k resolution, studio quality"
```

**步驟 2**：載入模型
```python
from happyhorse import HappyHorse

model = HappyHorse.load(version="1.1")
```

**步驟 3**：生成圖像
```python
image = model.generate(
    prompt="beautiful landscape...",
    steps=50,
    guidance_scale=7.5,
    seed=42
)
```

**步驟 4**：後製與優化
- 色彩校正
- 去噪 (denoise)
- 放大 (upscaling)

**預期結果**：高質量圖像，耗時 2-3 秒
